# دليل تعديل موقع samtconsult.com

كل التعديلات تتم من لوحة التحرير، بلا برمجة:
**https://app.pagescms.org** ← تسجيل الدخول بحساب GitHub ← اختيار المستودع.

بعد كل «حفظ» يُعاد بناء الموقع ونشره تلقائياً خلال دقيقتين تقريباً.

## الأقسام الثلاثة في اللوحة

**المشاريع — Projects**
- **إضافة مشروع:** زر Add ← املأ الحقول ← ارفع الصورة الرئيسية ← أضف الصور الإضافية ← Save.
- **إخفاء مشروع دون حذفه:** أوقف خيار «منشور على الموقع».
- **الصفحة الرئيسية:** فعّل «يظهر في الصفحة الرئيسية» (أربعة مشاريع على الأكثر).
- **الترتيب:** حقل «الترتيب» — الرقم الأصغر يظهر أولاً.

**صفحات إضافية — Extra pages** (التبويبات الجديدة)
- زر Add ← اكتب العنوان بالإنكليزية والعربية ← فعّل «تظهر كتبويب في القائمة».
- يظهر التبويب تلقائياً في القائمة العلوية وأسفل الموقع باللغتين.
- الأسماء المحجوزة (لا تستخدمها عنواناً إنكليزياً): Projects, Services, About, Contact.

**نصوص الموقع — Site text**
- كل نصوص الصفحات الرئيسية ومن نحن والخدمات والتواصل، باللغتين.
- الصورة الرئيسية للموقع وصورة المؤسس.

## قواعد الصور
- ارفع JPG بعرض ٢٠٠٠–٣٠٠٠ بكسل. الموقع يصغّرها ويحوّلها إلى WebP تلقائياً.
- تجنّب ملفات PNG الضخمة من برامج الرندر؛ صدّرها JPG أولاً.
- الصورة الرئيسية للموقع: يُفضَّل أن تكون فيها سماء واسعة في الأعلى.

## إن لم يظهر تعديل على الموقع
افتح المستودع على GitHub ← تبويب **Actions**. علامة ✓ خضراء تعني نجاح النشر.
علامة ✗ حمراء تعني خطأ في البيانات — افتحها، وأرسل لقطة الشاشة للمطوّر.

## للمطوّر
Astro 7 · المحتوى في `src/content` · الصور في `src/assets/images` · إعداد اللوحة في `.pages.yml`
النشر عبر GitHub Pages من `.github/workflows/deploy.yml`.
تشغيل محلي: `npm install` ثم `npm run dev`.
